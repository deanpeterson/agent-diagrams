How a skill reaches an agent — stored as an OCI image, discovered on demand

Authored as open SKILL.md folders → built by Konflux → Quay → mounted read-only as an image volume → loaded only when a task needs it

build & store — Konflux → Quay (OCI image) reference & mount — operator declares the image volume read-only image volume — /skills-catalog discover on demand — load SKILL.md when needed

Versioned, read-only, lazy. Skills are open SKILL.md folders baked into an OCI image by Konflux and pinned by tag on the AgentGateway. The operator mounts that image as a Kubernetes image volume — read-only, not a PVC (the workspace and KBs are the PVCs) — so every skill is present at near-zero cost. The agent keeps only a tiny index in its context and reads a skill’s full SKILL.md (and bundled files) only when a task calls for it — Anthropic-style progressive disclosure.
