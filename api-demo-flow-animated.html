One API, from template to audited traffic — what happens on OpenShift when a developer clicks Create

A developer fills in a Developer Hub template with an OpenAPI file. OpenShift GitOps builds the namespace, the Connectivity Link gateway takes the route and its policies, a consumer asks for a key and an owner approves it, and every call leaves a metric, a log line and a trace behind. Three ledgers answer "who did what".
