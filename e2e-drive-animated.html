Automated prompting, asserted outcomes. Each Tekton beat oc execs into the gateway pod and runs openclaw agent --agent <name> --message "<prompt>" — driving the same real agents you'd chat with, using the exact prompts a human would type (the chat beat goes through the mm-bridge instead). The agent does real, governed work; then the beat asserts the real result — a 6-card board, closed issues, a SUCCEEDED training run, a chat reply. Every beat green ⇒ the demo works.
