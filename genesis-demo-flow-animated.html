One platform: a web form becomes agents that plan, work, train a model, and talk back

The whole Genesis demo — on OpenShift: built by Konflux, reconciled by the operator, governed by Connectivity Link, grounded in skills + knowledge bases

build — Konflux → Quay compose & provision rotated credential — Vault → ESO plan & work — via the gateway → GitHub train & learn — OpenShift AI · MLflow chat — Mattermost

Self-service on top, guardrails underneath — all on OpenShift. Every image is built by Konflux; a Dev Hub form becomes desired state in Git that ArgoCD + the operator reconcile into the agents + knowledge bases; the agents act through Connectivity Link’s governed gateway with a credential that rotates every 30 min and that they never hold — planning a board, doing the work, training a model that provably learns, and answering you in chat. Reversible by deletion, and the whole flow is the genesis-e2e test suite.
