How the DNS and the load balancer get wired — you write four objects, controllers write the rest

Nobody edits a load balancer or a DNS zone by hand. A Gateway, an HTTPRoute, a TLSPolicy and a DNSPolicy go into Git; OpenShift GitOps applies them, OpenShift builds the gateway and gets it an address, cert-manager issues the certificate, and the Connectivity Link DNS Operator publishes the name. Then a request walks the chain.

configuration — Git, applied by OpenShift GitOps controllers building things — gateway, load balancer, address certificate — cert-manager DNS — records written and looked up a request — client to pod

The only thing you configure by hand is the DNS provider credential. Every hop after that, from load balancer to certificate to record, is written by a controller that watches the objects in Git, and rewritten when they change.
