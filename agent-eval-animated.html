Evaluating agents: the improvement loop

You don't retrain the model — you score the agent and fix the scaffolding around it. Measurably, on OpenShift AI.

the agent + its traces scoring — the scorecard the gaps — what failed improve the harness the model — frozen

You make the agent better, not the model. Every run is traced; an LLM-as-judge scores the whole trajectory against a scorecard — curated test cases and live production runs; the failures show exactly what to fix in the skills, tools, knowledge, and instructions; then you re-score. The model stays frozen — the loop improves everything around it. On OpenShift AI with DeepEval, TrustyAI LM-Eval (via the Llama Stack evaluation API), and the runtime Guardrails Orchestrator.
